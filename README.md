# ros2_odyssey 🤖

Autonomous differential-drive rover built with ROS2 Humble.

## What this project does
- SLAM-based mapping using slam_toolbox
- Autonomous navigation using Nav2 (planners, controllers, costmaps)
- Simulation in Gazebo with RViz2 visualisation
- Custom Python nodes for patrol and waypoint navigation

## Tech Stack
- ROS2 Humble
- Nav2 full stack
- slam_toolbox
- Gazebo
- Python / C++
- Ubuntu 22.04

## Project Structure
```
ros2_odyssey/
├── src/          # ROS2 packages
├── launch/       # Launch files
└── config/       # Nav2 parameters
```
